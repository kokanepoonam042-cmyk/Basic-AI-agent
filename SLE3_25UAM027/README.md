# Basic AI Agent

## Project Overview

This project is a basic AI Agent developed as part of a college project for the **AI-Augmented Workflow** course.

The purpose of this project is to understand how an AI Agent can communicate with a Large Language Model (LLM) through an API and how AI-assisted development can be used during software development.

## Objectives

The main objectives of this project are:

- Learn the basics of AI Agents.
- Learn how to use Python for AI development.
- Connect a Python application to the OpenAI API.
- Understand how an AI Agent receives and processes user input.
- Use Git and GitHub for version control.
- Practice AI-assisted coding and documentation.

## Technology Stack

- **Python** – Main programming language
- **OpenAI API** – Provides the Large Language Model
- **python-dotenv** – Loads environment variables
- **Git** – Version control
- **GitHub** – Project repository
- **Visual Studio Code** – Development environment
